Wan 视频 API

每条固定 5 秒，提交时必须填写 "duration": 5。缺少时长或填写其他时长时，接口返回 HTTP 400。

型号分辨率
wan4-wan3.0-480p480p
wan4-wan3.0-720p720p
wan4-wan3.0-1080p1080p
wan7-wan3.0-3默认分辨率
wan8-wan3.0默认分辨率
wan8-wan3.0-2默认分辨率

Wan4 的输出分辨率由型号名决定。请求里的 resolution 不会改变所选档位。请用 duration 表示时长。

提交视频

POST https://api.yuqitoken.cn/v1/videos
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{"model":"wan4-wan3.0-720p","prompt":"一艘船驶过湖面","duration":5}

查询任务

GET https://api.yuqitoken.cn/v1/videos/{task_id}
Authorization: Bearer YOUR_API_KEY
