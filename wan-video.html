Wan 视频 API

当前开放 Wan 3.0 官线的三个分辨率档，按秒计费。每次提交都要填写 2–30 的整数 duration，单位为秒。缺少时长或超出范围时，接口返回 HTTP 400。

型号分辨率时长
wan3.0-video-480p480P2–30 秒
wan3.0-video-720p720P2–30 秒
wan3.0-video-1080p1080P2–30 秒

输出分辨率由型号名决定。请求里的 resolution 不会改变所选档位。请用 duration 表示时长。此接口不接收 seconds 和 size。

Wan4、Wan7 和 Wan8 已暂停接收新单。已有任务可按原方式查询，退款仍按原流程处理。

双站接口

  • 企业站 https://yuqixk.xyz
  • 个人站 https://api.yuqitoken.cn

提交视频

POST https://api.yuqitoken.cn/v1/videos
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{"model":"wan3.0-video-720p","prompt":"一艘船驶过湖面","duration":8}

查询任务

GET https://api.yuqitoken.cn/v1/videos/{task_id}
Authorization: Bearer YOUR_API_KEY
